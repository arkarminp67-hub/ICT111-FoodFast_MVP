# Final Team Reflection — FoodFast RSU

## Key Learnings Across the Semester
Building FoodFast RSU from an initial problem hypothesis in Lab 02 to a user-tested MVP in Lab 14 taught our team the value of requirement traceability and user feedback. Iterating through Sprint 1, Sprint 2, Landing Page GTM, and User Testing demonstrated that technical development must always align with actual student pain points.

## What Went Well
* **Disciplined GitHub Workflow:** Maintaining a single shared repository with clear issue tracking enabled seamless collaboration across all 14 labs.
* **User-Centric Adjustments:** Testing results directly led to crucial UI fixes, such as auto-opening the basket drawer and adjusting vendor display contrast[cite: 4].
* **Privacy Compliance:** Implementing student PII phone masking (`081-XXX-XX89`) ensured user data protection on vendor dashboards[cite: 1].

## Challenges & Adaptations
* **Scope Management:** We initially planned full online payment gateway integration, but adapted to simulated cash-on-pickup checkout to deliver a stable, reliable prototype within semester deadlines[cite: 1].
