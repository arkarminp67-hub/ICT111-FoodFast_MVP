## System Architecture & Access
* **Platform:** Fully responsive Client-Side Web Application (HTML5 / CSS3 / ES6 Javascript / LocalStorage)[cite: 1].
* **Admin Switch:** Click the "Switch to Vendor Admin" button on the navigation drawer to toggle between the Student Consumer View and Vendor Kitchen Operations Dashboard[cite: 1].
* **Pre-Loaded Test Data:** Pre-populated with menu items, active sample orders, canteen building nodes (Building 6 & Building 11), and masked student contact numbers (`081-XXX-XX89`) for instant testing[cite: 1].
